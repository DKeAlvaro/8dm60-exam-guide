    Lectures 1–2#

    1. In autoregressive pretraining, where do the prediction targets come from?

    Why. The text labels itself: token $i$ is predicted from tokens before it. No annotator is involved. The model's own output would be self-training, and predicting hidden tokens from both sides is BERT-style masking, not autoregressive. (83% correct)

    2. In $h_i^{(0)} = e(x_i) + p_i$, what information does $p_i$ supply?

    Why. $p_i$ is a position vector added to the embedding so the model can tell the same word at different places apart. It carries no frequency, probability or confidence. (87% correct)

    3. What defines self-attention, as opposed to cross-attention?

    Why. Self-attention takes Q, K and V from the same sequence; cross-attention takes Q from one sequence and K/V from another. The projection matrices need not be identical. (59% correct)

    4. What distinguishes zero-shot from few-shot prompting?

    Why. The only difference is whether examples are in the prompt. Weights are frozen in both, and zero-shot still relies on pretraining. (45% correct — the trap was "no pretrained knowledge")

    5. For $W \in \mathbb{R}^{d \times k}$ and $\Delta W = BA$ of rank at most $r$, which shapes are compatible?

    Why. The inner dimension $r$ must match, and the product must be $d \times k$: $(d \times r)(r \times k)$. (90% correct)

    6. Why are different augmented views of an image used in visual self-supervision?

    Why. Two views of the same content teach invariance: representations stay consistent under changes that do not change the content. Augmentation can actually destroy detail, and it is not a substitute for a loss. (83% correct)

    7. What is the purpose of a contrastive image–text training objective?

    Why. Contrastive means pull matching pairs together and push mismatched pairs apart. It is not captioning, reconstruction or classification. (72% correct)

    8. Which statement distinguishes image-to-report retrieval from report generation?

    Why. Retrieval returns a neighbour from the archive; generation writes new text token by token. (93% correct)

    9. For fixed features $z = f_\theta(x)$, a linear probe uses $p = \mathrm{softmax}(Wz + b)$. Which parameters are fitted?

    Why. That is the definition of a probe: the encoder is frozen and only the small classifier on top is learned. (58% correct)

    10. What is external validation of a biomedical AI model, as opposed to an internal held-out test?

    Why. External means new data from another site, period or population. A random subset of the same dataset is internal validation. (93% correct)

    Lecture 6#

    11. When a model requests a search in a ReAct-style system, where does the resulting observation come from?

    Why. The model requests; the harness executes; the tool returns text. The tool description is instructions, not an observation. (36% correct — the biggest trap in the set)

    12. Which description best captures the ReAct approach?

    Why. ReAct is a loop, not a fixed plan and not post-hoc explanation. (83% correct)

    13. In ReAct's few-shot prompting setup, how do demonstrations influence the model?

    Why. In-context learning: examples in the prompt, no parameter updates. (73% correct)

    14. Why can external search help address the factual hallucinations discussed in ReAct?

    Why. Search grounds later reasoning in retrieved evidence; it does not update weights. (100% correct)

    15. What is the main distinction between workflows and agents?

    Why. The question is who chooses the next step. Neither design updates the weights. (74% correct; 22% fell for the weight-update trap)

    16. One LLM call extracts findings, a second drafts a summary, a third translates it. Which pattern is this?

    Why. Fixed sequential stages, each consuming the previous output: chaining. (100% correct)

    17. A system classifies a request and sends it to one of several specialist handlers. Which pattern is this?

    Why. One path is selected. Parallelization runs several paths and aggregates. This is the most likely trap to reappear. (The class voted 100% for parallelization.)

    18. Which capability is least directly tested by a static medical multiple-choice benchmark?

    Why. Static questions test recall and single-step association; they cannot test interactive information gathering. (84% correct)

    19. What is the role of agent-based modelling in the proposed clinical evaluations?

    Why. It simulates participants behaving in an environment, so a system can be tested against realistic interaction. (Not a replacement for the encounter.)

    20. An agent performs well in a clinical simulation. Which further step best addresses whether that result transfers to actual care?

    Why. Simulation cannot establish transfer. Real-world studies plus post-deployment monitoring are the evidence. (90% correct)

    Traps to remember#

    Tempting option Why it is wrong
    Workflows train or update weights Both workflows and agents keep the weights fixed
    Parallelization for a router Routing selects one path; parallelization runs all
    Tool description equals observation The program executes the tool; the description is only instructions
    Few-shot equals fine-tuning Demonstrations are in context; weights unchanged
    Zero-shot equals no pretrained knowledge It uses pretraining, just no demonstrations
    Retrieval generates reports Retrieval selects an existing report
    Balanced test set gives real precision Precision depends on prevalence
    0.90 softmax equals 90% disease probability Softmax is relative to the candidate set
    AUROC 0.97 settles the threshold AUROC is threshold-free; the point is a clinical decision
